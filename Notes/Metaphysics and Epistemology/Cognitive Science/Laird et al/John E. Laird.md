# Abstract

What is SOAR?
	Soar is meant to be a general cognitive architecture (Langley et al., 2009) that provides the fixed computational building blocks for creating AI agents whose cognitive characteristics and capabilities approach those found in humans (Laird, 2012; Newell, 1990).

Designing LLMs
	Designing cognitive architecture means
		- create sufficient structure to support coherent and purposeful behavior
		- provide sufficient flexibility so agent can adapt (learn) to specifics of its task and environment

Enter SOAR
	Laird & Rosenbloom, 1996; Laird, 2012

- Developed in 1980s
	- architecture to support multi-task, multi-method problem-solving
